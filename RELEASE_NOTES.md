# Version 1.0.0

First public data release for the preprint “Degree-conditioned anneal offsets reshape certified-optimum sampling for minimum vertex cover.”

The ZIP archive contains the recorded QPU and simulated-annealing outputs, metadata, analysis-ready and derived tables, analysis scripts, and manuscript figures. The repository contains the code, metadata, figures, and documentation in a form that can be browsed without downloading the full dataset.
